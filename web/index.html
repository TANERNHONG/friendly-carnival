      05 — Telegram

      Signals to your phone.

      Deals from each scan, alerts before tracked auctions end, and a note with the final price when they sell. Reply to the bot with /track <link> to add one from your phone.

      Setup

      1. In Telegram, message @BotFather → /newbot → copy the token.
      2. Put it in .env as TELEGRAM_BOT_TOKEN=… and restart Carnival.
      3. Open your bot and send /start. The first chat to do so becomes the only chat it talks to.
      4. Press Send test. Commands: /deals /ending /list /track /scan /pricelist /add.
